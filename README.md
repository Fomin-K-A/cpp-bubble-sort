# cpp-bubble-sort

Моя реализация алгоритма сортировки «пузырьком» (Bubble Sort) на C++.

## 📌 Особенности реализации
* **Шаблонность (`template <typename T>`)**: Алгоритм работает с любыми типами данных, для которых определен оператор `<` (числа, строки и т.д.).
* **Оптимизация (ранний выход)**: Если за очередной проход не было совершено ни одного обмена, массив считается отсортированным, и цикл прерывается. Это даёт сложность **O(n)** в лучшем случае (для уже отсортированного массива).
* **Оптимизация внутреннего цикла**: Внутренний цикл идёт до `j > i`, так как после каждого прохода `i` элементов в начале массива уже стоят на своих местах.
* **Вынесение в заголовочный файл**: Реализация находится в `bubble_sort.h`, что позволяет легко подключать её в другие проекты.

## 📂 Структура проекта
* `bubble_sort.h` — заголовочный файл с шаблонной функцией `bubbleSort`.
* `main.cpp` — файл с набором тестов (проверка обычного массива, уже отсортированного, обратного порядка, дубликатов и строк).

## 🚀 Как собрать и запустить

Для сборки используется компилятор `clang++` (стандарт C++17).

```bash
# Сборка
clang++ -std=c++17 -pedantic-errors main.cpp -o main.exe

# Запуск
./main.exe
